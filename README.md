# Clone E-Commerce Website

This project is a **clone of an e-commerce website for electronic products**, created as part of my learning journey with **Git and GitHub**.

I built this project while following the **Git and GitHub tutorial by Code With Harry**. The main purpose of this project was to understand how Git and GitHub are used in a real development workflow, while also getting hands-on experience with the structure and development of a basic e-commerce website.

## 📌 About the Project

The website is designed around an online electronics store where users can browse different electronic products. It recreates the basic structure and appearance of a modern e-commerce website, including product sections, navigation, and other common elements found on shopping websites.

This project was primarily created for **learning and practice purposes** rather than as a production-ready e-commerce application.

## 🎯 What I Learned

While working on this project, I gained practical experience with:

* Creating and managing a Git repository
* Initializing a project with Git
* Tracking changes using Git
* Creating commits with meaningful messages

* Working with branches
